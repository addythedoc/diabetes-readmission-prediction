# Data Directory

This project uses the **UCI Diabetes 130-US Hospitals Dataset**.

## Raw Data
- Source: UCI Machine Learning Repository
- Dataset: Diabetes 130-US hospitals (1999–2008)
- URL: https://archive.ics.uci.edu/ml/datasets/diabetes+130-us+hospitals+for+years+1999-2008

Raw data files are **not included** in this repository.

## Processed Data
- File: `diabetes_processed.csv`
- Generated by: `scripts/01_load_clean.R`
- Description:
  - Cleaned column names
  - Missing values standardized
  - Binary outcome `readmitted_30` created
  - Variables formatted for modeling

The processed dataset exceeds GitHub file size limits (>25MB) and is therefore **excluded**.

## Reproducibility
To recreate the processed dataset:
1. Download the raw CSV from the UCI repository
2. Place it in `data/raw/`
3. Run `scripts/01_load_clean.R`

All downstream analyses use the generated processed file.
